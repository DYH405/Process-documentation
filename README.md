# Process-documentation

存放「面向室内巡检任务的 ROS2 移动机器人故障检测与分级恢复」课题的过程文档。

代码仓库：[DYH405/ROS2-](https://github.com/DYH405/ROS2-)

## 用途

本仓库只放**说明性文档**，不放可执行代码。目的是让"三个月后回看"和"接手他人代码"时，能快速回答三个问题：

1. 这个数据/功能是哪段代码产生的？
2. 它的值从哪里来？
3. 它可能在什么情况下出错？

## 目录约定

```
docs/
  NN-主题.md        技术说明，按主题编号
tasks/
  T-XXX.md          任务卡，原样存档，不修改
archive/
  YYYY-MM-DD-xxx.md 阶段归档，上下文压缩/换会话时恢复用
pointers/
  当前指针.md        当前任务指针与收敛检查说明
```

每份文档开头标注**最后更新日期**和**对应代码提交**，避免文档与代码版本错位。

## 写作约定

- 说明**为什么**，不重复代码已经表达的**是什么**
- 每个结论都要能追溯到具体文件与行号
- 已知问题、版本差异必须显式标注，不做隐含假设
